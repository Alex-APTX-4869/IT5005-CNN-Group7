# IT5005-CNN-Group7

IT5005 group project: vision-language models with CLIP.

## Files

- `IT5005_Project_August_2026.pdf`: original project brief.
- `Part_1.ipynb`: CLIP zero-shot classification and probing template.
- `Part_2.ipynb`: CLIP image-text retrieval and PEFT/LoRA template.
- `project_requirements.txt`: supplied Python dependencies.
- `id_to_label.json`: supplied ImageNet class labels; keep alongside Part 1.

## Setup

Use Python 3.12 in a separate environment, then run:

```bash
python -m pip install -r project_requirements.txt
jupyter lab
```

Open the notebooks in Jupyter. These are the original templates; implementation and experiment results still need to be completed. See the project brief and notebook cells for the assignment requirements.

## Collaboration

Use a separate branch for each task and open a pull request before merging into `main`. Coordinate notebook edits so that two people do not edit the same notebook cells simultaneously. Keep local caches, downloaded datasets, model weights and environment files out of Git.

The repository owner can invite group members through **Settings → Collaborators → Add people**. A public repository is readable by everyone; direct pushes require collaborator access.

## AI usage

Record any generative AI assistance used for the assignment in each notebook's AI Usage cell. The original assignment files are preserved unchanged in the initial repository setup.
